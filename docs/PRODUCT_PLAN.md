# Think Block 학습 서비스 기획

## 제품 한 문장

Think Block은 코드를 아직 쓰지 못하는 학습자도 `데이터 → 전처리 → 모델 → 평가`의 흐름을 블록으로 직접 조립하고, 브라우저에서 바로 실행하며 AI의 원리를 익히는 실습실이다.

## 핵심 사용자와 문제

- 중·고등학생과 AI 입문자: 수식과 코드보다 결과가 생기는 흐름을 먼저 이해하고 싶다.
- 교사와 멘토: 설치나 계정 설정 없이 재현 가능한 실습을 제공하고 싶다.
- 비전공 학습자: 모델을 실행하는 데서 끝나지 않고, 결과가 좋은지 판단하는 법까지 배우고 싶다.

기존 프로토타입은 그래프 편집과 기초 통계 계산은 가능하지만, 처음 무엇을 만들어야 하는지 안내가 없고 실제 모델 학습·예측·평가 단계가 연결되지 않는다. 프로젝트 보존과 실행 오류 안내도 부족해 한 차시 수업을 완주하기 어렵다.

## 학습 루프

1. 예제를 연다 — 빈 화면 대신 완성 가능한 출발점을 제공한다.
2. 블록을 살펴본다 — 각 블록은 역할, 입출력, 범주를 설명한다.
3. 흐름을 바꾼다 — 포트를 연결하고 값을 조정한다.
4. 실행한다 — 현재 실행 중인 블록과 실패 지점을 보여준다.
5. 결과를 해석한다 — 손실과 평가 지표가 의미하는 바를 수업 패널에서 확인한다.
6. 저장하고 다시 연다 — JSON 파일과 브라우저 자동 저장으로 실습을 이어간다.

## MVP 범위

### 그래프 제작

- 검색 가능한 블록 라이브러리와 우클릭 빠른 추가
- 단일 입력 포트 연결 보장, 중복 연결 방지, 순환 그래프 차단
- 노드 다중 선택·삭제, 캔버스 이동·확대/축소·초기화
- 빈 캔버스 안내와 키보드 단축키 안내

### AI 파이프라인

- 데이터: 숫자, CSV, 선형 샘플 데이터
- 전처리: 정규화, 학습/테스트 분리
- 모델: 선형 회귀 학습
- 추론: 예측
- 평가: 평균제곱오차(MSE)
- 기초 연산과 기술 통계

### 학습 경험

- 첫 모델, 데이터 이해, 직접 해보기의 3개 수업
- 그래프 구성과 실행 결과를 감지하는 체크리스트
- 수업별 시작 예제와 핵심 개념 설명
- 블록별 쉬운 설명과 예상 입출력

### 프로젝트 운영

- 브라우저 자동 저장
- 프로젝트 JSON 내보내기·불러오기
- 새 프로젝트와 예제 갤러리
- 실행 진행률, 성공 시간, 노드별 실패 표시

## 정보 구조

```text
┌ 블록·파일 ┐ ┌────────── 프로젝트 / 실행 상태 ──────────┐ ┌ 오늘의 수업 ┐
│ 검색       │ │                                           │ │ 개념         │
│ 데이터     │ │              그래프 캔버스                │ │ 체크리스트   │
│ 전처리     │ │                                           │ │ 힌트/예제    │
│ 모델       │ │                                           │ │ 다음 수업    │
│ 평가       │ └───────────────────────────────────────────┘ └──────────────┘
│ 파일       │
└────────────┘
```

## 시각 원칙

- 어두운 청사진 캔버스를 중심에 두고 패널은 반투명한 잉크색으로 낮춘다.
- 데이터(파랑), 전처리(민트), 모델(보라), 평가(앰버)를 노드 헤더와 포트에 일관되게 쓴다.
- 실행 상태와 학습 체크는 문장과 아이콘을 함께 써 색상만으로 전달하지 않는다.
- 둥근 카드의 반복을 피하고, 패널 구분선과 작은 상태 레일로 구조를 표현한다.

## 출시 단계

### 1단계 — 완주 가능한 로컬 MVP

현재 구현 범위다. 선형 회귀 수업을 처음부터 끝까지 실행하고 결과를 저장할 수 있어야 한다.

### 2단계 — 교실 운영

- 교사용 수업 링크와 읽기 전용 템플릿
- 학생별 제출물과 루브릭
- 실행 로그·진도 집계
- 접근성 점검과 다국어 콘텐츠

### 3단계 — 모델 확장

- 로지스틱 회귀, 결정 트리, 간단한 신경망
- 이미지/텍스트 데이터 블록
- 학습 곡선과 혼동 행렬 시각화
- 모델 내보내기와 추론용 공유 링크

## 성공 지표

- 첫 방문 후 10분 안에 첫 모델 실행 성공률 70% 이상
- 시작한 수업의 체크리스트 완주율 60% 이상
- 실행 오류 후 2분 안에 복구하는 비율 80% 이상
- 프로젝트 저장 후 7일 이내 재방문율 25% 이상

## 품질 기준

- 빈 프로젝트, 정상 실행, 입력 누락, 순환 연결, 파일 오류 상태에 모두 다음 행동이 보인다.
- 1024px 이상에서는 세 패널을 동시에 쓰고, 작은 화면에서는 보조 패널을 접을 수 있다.
- 키보드 포커스가 보이고 애니메이션 감소 설정을 존중한다.
- 프로덕션 빌드와 린트가 오류 없이 완료된다.
